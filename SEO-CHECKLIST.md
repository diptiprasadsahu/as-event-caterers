# SEO launch checklist

- [ ] Publish through GitHub Pages and confirm the exact public URL.
- [ ] Add canonical URL and `og:url` to `index.html`.
- [ ] Add `sitemap.xml` using that exact URL and reference it in `robots.txt`.
- [ ] Confirm the homepage returns successfully over HTTPS.
- [ ] Check mobile layout and all navigation, enquiry, email, phone and WhatsApp links.
- [ ] Submit a real enquiry and verify inbox delivery.
- [ ] Add/verify the site in Google Search Console and submit sitemap.
- [ ] Inspect the homepage URL and request indexing.
- [ ] Validate JSON-LD with Google's Rich Results Test / Schema Markup Validator.
- [ ] Add a real, publicly accessible social preview image later if desired; do not use a local or Base64-only image URL for `og:image`.
- [ ] Complete Google Business Profile with the accurate business address/service area and collect genuine customer reviews.

- [ ] Confirm the browser tab displays the `favicon.png` icon after deployment.
